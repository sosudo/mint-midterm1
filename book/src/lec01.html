A Little Bit of History

It all started in the 1850's when Riemann questioned the meaning of $$\int_a^b f(x)\,dx.$$ This concept of integration goes back to the classic antiquity to calculate certain areas, volumes, centers of mass, etc, i.e., the theory of integration.

The modern theory of integration took the form by which it is known today since the 17th century, with the works of Newton and Leibniz, and before them Fermat and Barrow.

This determines the birth of infinitesimal calculus: the dichotomy between integration and differentiation, basically as "inverse operations of each other", and we call the Fundamental Thm. of Calculus:

  • $\displaystyle F(x) = \int_a^x f(t)\,dt \;\Rightarrow\; F'(x) = f(x)$
  • $\displaystyle F'(x) = f(x) \;\Rightarrow\; \int_a^b f(t)\,dt = F(b) - F(a).$

In the beginning of the 19th century, Cauchy initiated the study of rigorous ideas central to Calculus, such as:

  • limit
  • derivative
  • integral
  • continuity, etc.

and introduced the first satisfactory notion of integral, albeit restricted to continuous functions.

In the middle of the 19th century, and motivated by questions posed by Fourier, Riemann developed the Theory of Integration:

  • which functions can be represented by a Fourier series?
  • how can one solve partial differential equations issuing from mathematical physics?
  • what do we mean by "function"?
  • and he noted that the notion of integration should be extended to some non-continuous functions…

This motivated the notion of Lebesgue integral: just as the real numbers "complement" the rational numbers, we'll see that functions Lebesgue integrable "complement" those functions integrable in the sense of Riemann.

Today, the Theory of (Lebesgue) Integration central to Mathematics, is intrinsically relevant to

  • Functional Analysis
  • Calculus of Variations
  • Differential Equations
  • Probability Theory,
  • Etc.

and is ubiquitous in Engineering, Economics, Biology, etc.

According to Lebesgue, the "geometric definition of integral" is:

the integral of a non-negative function $f$ = measure of the region under the graph

Now, this leads to the question of what is a measure, which sets can be attributed a measure (i.e., are measurable sets).

Elementary sets

Consider the problem of measurement of length of subsets of $\R$, e.g., we aim at defining the length $\mu$ of subsets of $I := [0,1]$.

If $J \subset I$ is an interval of the form $$(a,b),\quad [a,b),\quad (a,b],\ \text{or}\ [a,b],$$ we set $\mu(J) := |b-a|$.

For a finite union of disjoint intervals $J_1,\dots,J_n$, set $$\mu\Big(\bigcup_{i=1}^n J_i\Big) := \sum_{i=1}^n \mu(J_i).$$

This collection of sets is called the collection of elementary sets. (later on, we will restrict the notion of elem. sets to intervals)

How can we extend the measure to non-elementary sets? Going back to antiquity, a natural idea is to approximate non-elementary sets by elementary sets.

But using what notion of approximation?

Jordan measure

The construction that leads to the so called Jordan measure (or Peano-Jordan measure) is this: a set $A \subset I$ is Jordan measurable if $\forall \eps > 0$ $\exists$ elementary sets $A_\eps, B_\eps$ s.t. $$A_\eps \subset A \subset B_\eps \quad\text{and}\quad \mu(B_\eps \setminus A_\eps) \lt \eps$$ (N.B. $A_\eps, B_\eps$ elementary sets $\Rightarrow B_\eps \setminus A_\eps$ elementary set

An elementary set is a finite disjoint union of intervals. Removing one interval from another leaves at most two intervals (e.g. $[0,1]\setminus(0.3,0.5] = [0,0.3]\cup(0.5,1]$), and removing a finite union just repeats this finitely many times. So $B_\eps\setminus A_\eps$ is again a finite union of intervals, which we can rearrange to be disjoint.

& $\mu(B_\eps\setminus A_\eps) = \mu(B_\eps) - \mu(A_\eps)$

Since $A_\eps \subset B_\eps$, we can split $B_\eps$ as the disjoint union $B_\eps = A_\eps \cup (B_\eps\setminus A_\eps)$ of two elementary sets. Additivity of $\mu$ on disjoint elementary sets gives $\mu(B_\eps) = \mu(A_\eps) + \mu(B_\eps\setminus A_\eps)$; now subtract $\mu(A_\eps)$, which is finite.

).

When $\eps \to 0$, $\mu(B_\eps)$ and $\mu(A_\eps)$ will have a common limit

Every inner set has $\mu(A_\eps) \le \mu(B_\delta)$ for every outer set (since $A_\eps \subset A \subset B_\delta$). So $s := \sup_\eps \mu(A_\eps) \le \inf_\delta \mu(B_\delta) =: S$. But $S - s \le \mu(B_\eps) - \mu(A_\eps) \lt \eps$ for every $\eps$, so $s = S$, and both $\mu(A_\eps)$ and $\mu(B_\eps)$ are squeezed to this number: $s - \eps \lt \mu(A_\eps) \le s \le \mu(B_\eps) \lt s+\eps$.

, which we'll define as $\mu(A)$.

With this procedure many sets are not Jordan measurable. Indeed, $\Q\cap I$ contains no elementary set of positive measure

An elementary set of positive measure contains a non-degenerate interval $(c,d)$, $c \lt d$. But every such interval contains irrational numbers (e.g. $c + (d-c)/\sqrt2$), so it is not contained in $\Q\cap I$. Hence every inner approximation $A_\eps \subset \Q\cap I$ is a finite set of points, of measure $0$.

, but any elementary set containing $\Q\cap I$ has $\mu$-measure $1$

Let $B = J_1\cup\dots\cup J_n \supset \Q\cap I$. The closure of $B$ is $\overline{J_1}\cup\dots\cup\overline{J_n}$ (finite union of closed intervals), a closed set containing $\Q\cap I$, which is dense in $I$. So $\overline B \supset I$. Adding endpoints doesn't change lengths, so $\mu(B) = \mu(\overline B) \ge \mu(I) = 1$; and $B\subset I$ gives $\le 1$.

So inner measure $0$, outer measure $1$: the gap $\mu(B_\eps\setminus A_\eps)$ is always $1$.

.

Still, $\mu$ has nice properties such as

  • additivity: $\mu(A\cup B) = \mu(A) + \mu(B)$, if $A\cap B = \emptyset$ and $A, B$ are Jordan measurable [can be extended to countably many]
  • translation invariance: $\mu(a + A) = \mu(A)$

Lebesgue's idea: outer measure

So a more inclusive extension of $\mu$ was proposed by Lebesgue, changing the way of approximating by elementary sets:

  • introduce the outer measure $\ms(A)$ for every set $A \subset I$: $$\ms(A) := \inf\Big\{\sum_{n=1}^\infty \mu(A_n) : A_n \text{ elementary sets},\ A \subseteq \bigcup_{n=1}^\infty A_n\Big\}.$$ We'll see (Prop 2.9) $A$ elem. set $\Rightarrow \ms(A) = \mu(A)$

A set $A$ is said to be Lebesgue measurable if $$\ms(A) + \ms(I\setminus A) = \mu(I)$$ (cf. Def 3.1 and Hmw #1, (2) See Rmk 3.13*)

Elementary sets are Lebesgue measurable. Equivalently, $A$ is Lebesgue measurable iff $\forall\eps\gt 0$ $\exists A_\eps$ elementary set s.t. $$\ms(A\,\triangle\,A_\eps) \lt \eps,$$ where $A\triangle B := (A\setminus B)\cup(B\setminus A)$ (symmetric difference).

N.B. unlike the Jordan measure, no inclusion of elementary sets is required.

This "nuance" leads to a substantial enlargement of the class of measurable sets, to the extent that the existence of non-Lebesgue measurable sets is anchored on deep set-theoretic axioms. (e.g. axiom of choice)

It is then a fact that countable unions and intersections of Lebesgue measurable sets are still Lebesgue measurable, complements of measurable sets are measurable, countable additivity still holds, etc.

N.B. Countable additivity is a necessity: think about approximating a disc by unions of rectangles…

Lebesgue Measure of a set: in $\R$ ~ length; in $\R^2$ ~ area; in $\R^3$ ~ volume.

1. A Brief Overview of the Riemann Integral

Let $a, b\in\R$, $a \lt b$. A partition of $[a,b]$ is a set $\{x_0,\dots,x_n\}$, $n\in\N$, with $x_i \neq x_j$ if $i\ne j$, and $$x_0 = a \lt x_1 \lt \dots \lt x_n = b.$$

Let $f:[a,b]\to\R$ be a bounded function, and let $P = \{x_0,\dots,x_n\}$ be a partition of $[a,b]$. The lower Riemann sum is $$L(f,P,[a,b]) := \sum_{i=1}^n (x_i - x_{i-1}) \inf_{[x_{i-1},x_i]} f$$

The upper Riemann sum is $$U(f,P,[a,b]) := \sum_{i=1}^n (x_i - x_{i-1}) \sup_{[x_{i-1},x_i]} f$$

Clearly $L(f,P,[a,b]) \le U(f,P,[a,b])$

Term by term: on each $[x_{i-1},x_i]$ we have $\inf f \le \sup f$ (the interval is non-empty), and the weight $x_i - x_{i-1}$ is positive. Multiplying an inequality by a positive number keeps it, and adding $n$ such inequalities gives the claim.

Let $P$ and $P'$ be partitions of $[a,b]$. $P'$ is said to be finer than $P$ if $P\subseteq P'$. ($P'$ has more points).

Let $f:[a,b]\to\R$ be a bounded function, and let $P$ and $P'$ be partitions of $[a,b]$, with $P'$ finer than $P$. Then $$L(f,P,[a,b]) \le L(f,P',[a,b]) \le U(f,P',[a,b]) \le U(f,P,[a,b])$$ In particular, if $P$ and $P'$ are arbitrary partitions of $[a,b]$, then $$L(f,P,[a,b]) \le U(f,P',[a,b]). \tag{*}$$

Let $P = \{x_0,\dots,x_n\}$ and $P' = \{x'_0,\dots,x'_N\}$, $N \gt n$. $\forall j = 1,\dots,n$, let $k\in\{0,\dots,N-1\}$ s.t. $$x_{j-1} = x'_k \lt x'_{k+1} \lt \dots \lt x'_{k+m} = x_j$$ for some $m\ge1$ s.t. $k+m\le N$.

Because $P\subseteq P'$, both endpoints $x_{j-1}$ and $x_j$ are points of $P'$; call their positions in $P'$ $k$ and $k+m$. The points of $P'$ strictly between them (there are $m-1\ge 0$ of them) cut $[x_{j-1},x_j]$ into $m$ consecutive pieces. So each coarse interval is exactly a union of consecutive fine intervals.

Then

$$(x_j - x_{j-1})\inf_{[x_{j-1},x_j]} f = \sum_{i=1}^m (x'_{k+i} - x'_{k+i-1}) \inf_{[x_{j-1},x_j]} f$$

(telescoping sum) The lengths of the fine pieces add up to the length of the coarse interval: $$\sum_{i=1}^m (x'_{k+i}-x'_{k+i-1}) = x'_{k+m} - x'_k = x_j - x_{j-1},$$ since all the intermediate points cancel. Then multiply by the constant $\inf_{[x_{j-1},x_j]} f$ and distribute it over the sum.

$$\le \sum_{i=1}^m (x'_{k+i} - x'_{k+i-1}) \inf_{[x'_{k+i-1},\,x'_{k+i}]} f$$

Each fine piece $[x'_{k+i-1},x'_{k+i}]$ is a subset of $[x_{j-1},x_j]$, and the infimum over a smaller set is at least as large: every value of $f$ on the small piece is $\ge \inf_{[x_{j-1},x_j]} f$, so that number is a lower bound there, hence $\le$ the greatest lower bound $\inf_{[x'_{k+i-1},x'_{k+i}]}f$. Multiply by the positive length and add.

Picture: one wide rectangle at the lowest height of the whole interval sits under several narrow rectangles, each of which can rise to the lowest point of its own piece.

and thus $L(f,P,[a,b]) \le L(f,P',[a,b])$.

Sum the previous inequality over $j=1,\dots,n$. On the left we get exactly $L(f,P,[a,b])$. On the right, as $j$ runs over all coarse intervals, the fine pieces run over every interval of $P'$ exactly once (the coarse intervals are disjoint except at endpoints and cover $[a,b]$), so we get $L(f,P',[a,b])$.

Similarly, $U(f,P',[a,b]) \le U(f,P,[a,b])$

Same argument with $\sup$ in place of $\inf$: the supremum over a smaller set is at most the supremum over the larger set, so the inequality flips. Fine upper rectangles can only come down.

, and use 1.3.

N.B. 1.3 gives the middle inequality $L(f,P',[a,b]) \le U(f,P',[a,b])$ (it holds for any single partition, in particular for $P'$). Chaining the three gives the displayed line.

Let now $P$ and $P'$ be arbitrary partitions of $[a,b]$ and set $P'' := $ "$P\cup P'$", the partition that contains all points of $P$ and all points of $P'$. Then $P''$ is finer than $P$ and $P'$

$P\subseteq P\cup P'$ and $P'\subseteq P\cup P'$ by definition of union, and $P\cup P'$ is a genuine partition: it is finite, contains $a$ and $b$, and listing its points in increasing order gives $x_0 = a \lt \dots \lt b$.

, so

$$L(f,P,[a,b]) \le L(f,P'',[a,b]) \le U(f,P'',[a,b]) \le U(f,P',[a,b]).\ \blacksquare$$

Apply the first part twice. With $P''$ finer than $P$: $L(f,P) \le L(f,P'')$. With $P''$ finer than $P'$: $U(f,P'') \le U(f,P')$. The middle inequality is N.B. 1.3 for $P''$. Note the trick: we compare two unrelated partitions by going through a common refinement.

Let $f:[a,b]\to\R$ be a bounded function. The lower Riemann integral of $f$ is $$L(f,[a,b]) := \sup_{P \text{ partition}} L(f,P,[a,b]).$$ The upper Riemann integral of $f$ is $$U(f,[a,b]) := \inf_{P\text{ partition}} U(f,P,[a,b])$$

By Prop 1.5 $(*)$ $$L(f,[a,b]) \le U(f,[a,b]).$$

Fix any partition $P'$. By $(*)$, $U(f,P',[a,b])$ is an upper bound for all lower sums $L(f,P,[a,b])$, so it is $\ge$ their least upper bound: $L(f,[a,b]) \le U(f,P',[a,b])$. Now $L(f,[a,b])$ is a lower bound for all upper sums, so it is $\le$ their greatest lower bound $U(f,[a,b])$.

Let $f:[a,b]\to\R$ be a bounded function. $f$ is said to be Riemann integrable if $$\boxed{L(f,[a,b]) = U(f,[a,b])},$$ in which case we define $$\int_a^b f := L(f,[a,b]) = U(f,[a,b]).$$ (or $\int_a^b f(x)\,dx$)

$$(b-a)\inf_{[a,b]} f \le \int_a^b f \le (b-a)\sup_{[a,b]} f.$$

Use the trivial partition $P_0 = \{a,b\}$ with a single interval. Then $L(f,P_0,[a,b]) = (b-a)\inf_{[a,b]} f$ and $U(f,P_0,[a,b]) = (b-a)\sup_{[a,b]}f$. Since the lower integral is the sup of lower sums, $\int_a^b f = L(f,[a,b]) \ge L(f,P_0,[a,b])$; since the upper integral is the inf of upper sums, $\int_a^b f = U(f,[a,b]) \le U(f,P_0,[a,b])$.

It can be easily proved that

Let $f,g:[a,b]\to\R$ be bounded Riemann integrable functions. Then $\alpha f + \beta g$ is Riemann integrable for all $\alpha,\beta\in\R$ and $$\int_a^b(\alpha f + \beta g) = \alpha\int_a^b f + \beta\int_a^b g.$$

If $f:[a,b]\to\R$ is continuous then $f$ is Riemann integrable.

Since $f$ is continuous on a closed, bounded interval, then $f$ is bounded and uniformly continuous.

Two classical theorems for continuous functions on a compact interval $[a,b]$: the extreme value theorem ($f$ attains a max and a min, so it is bounded) and the Heine–Cantor theorem (continuity on a compact set is uniform). Both use compactness of $[a,b]$ (Bolzano–Weierstrass); both fail on, e.g., $(0,1]$, where $1/x$ is continuous but unbounded.

Let $\eps\gt 0$ and choose $\delta\gt 0$ such that $$s,t\in[a,b],\ |s-t|\lt\delta \;\Rightarrow\; |f(s)-f(t)|\lt\eps. \tag{*}$$

This is literally the definition of uniform continuity: for each $\eps$ there is one $\delta$ that works for all pairs $s,t$ at once, regardless of where they are in $[a,b]$. (Plain continuity would only give a $\delta$ depending on the point.)

Let $n\in\N$ be such that $\frac{b-a}{n} \lt \delta$

Archimedean property: $n \gt (b-a)/\delta$ exists since $\N$ is unbounded in $\R$.

, and choose an equally spaced partition $P = \{x_0 = a,\dots,x_n = b\}$ with $$x_j - x_{j-1} = \frac{b-a}{n},\quad j = 1,\dots,n.$$ Then

$$U(f,[a,b]) - L(f,[a,b]) \le U(f,P,[a,b]) - L(f,P,[a,b])$$

$U(f,[a,b])$ is the infimum of all upper sums, so $U(f,[a,b]) \le U(f,P,[a,b])$; $L(f,[a,b])$ is the supremum of all lower sums, so $L(f,[a,b]) \ge L(f,P,[a,b])$, i.e. $-L(f,[a,b]) \le -L(f,P,[a,b])$. Add.

$$= \frac{b-a}{n}\sum_{i=1}^n\Big(\sup_{[x_{j-1},x_j]} f - \inf_{[x_{j-1},x_j]} f\Big)$$

Subtract the two sums term by term; every interval has the same length $\frac{b-a}{n}$, which factors out of the sum.

$$\underset{(*)}{\le} \frac{b-a}{n}\, n\, \eps = (b-a)\cdot\eps.$$

Any two points $s,t$ in the same interval $[x_{j-1},x_j]$ satisfy $|s-t| \le \frac{b-a}{n} \lt \delta$, so by $(*)$: $f(s) \lt f(t) + \eps$. Taking sup over $s$ and inf over $t$: $\sup f - \inf f \le \eps$ on each interval. (Sup and inf exist since $f$ is bounded; in fact they're attained.) There are $n$ terms, each $\le\eps$.

Letting $\eps\to0^+$ we conclude that $U(f,[a,b]) \le L(f,[a,b])$, hence $=$.

The left side $U(f,[a,b]) - L(f,[a,b])$ is a fixed number (it doesn't depend on $\eps$), and it is $\le (b-a)\eps$ for every $\eps\gt0$, so it is $\le 0$. Combined with Rmk 1.7 ($L \le U$) we get equality, i.e. $f$ is Riemann integrable (Def 1.8).
