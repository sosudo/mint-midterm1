# Measure & Integration: lecture notes

The handwritten lecture notes are the `Lect*.pdf` scans in this folder.
`docs/` holds an interactive textbook version of them, served by GitHub Pages:

- **Transcribed text.** All 12 lectures are typeset with KaTeX. Each block links back to the scanned page it came from ("original notes · p. N").
- **Proof-step explanations.** Every underlined step in a proof can be hovered (or tapped) to show why it holds.
- **Narrated lecture.** The ▶ bar at the bottom reads and explains the lecture aloud. It uses a natural neural voice ([Kokoro-82M](https://github.com/thewh1teagle/kokoro-onnx), voice `af_heart`) that is pre-rendered to MP3 files in `docs/audio/`, so it works offline. The ⚙ menu switches to the device's own voice (Web Speech API) and sets the speed.
- **Explainers.** These are short narrated animations, one per lecture, in the spirit of 3Blue1Brown: Riemann vs. Lebesgue, the ε/2ⁿ trick, the Vitali set, Carathéodory's criterion, the Cantor staircase, Borel–Cantelli, π–λ systems, regularity, simple-function approximation, and more.
- **Interactive figures.** These are sliders and draggable diagrams: Riemann sums, Jordan inner/outer approximations, Hausdorff dimension, σ-algebras generated by sets, continuity of measure, and others.

## Layout

```
book/src/lecNN.html     lecture content (transcription, <span class="step">…<span class="why">…</span></span>, <template class="say">narration</template>)
book/assets/book.js     runtime: KaTeX, step popovers, narrated reader, explainer player, figure helpers
book/assets/lecNN.js    that lecture's figures and explainer scenes
book/build.py           assembles docs/ and (with --audio) synthesises narration
book/lint.py            catches HTML nesting mistakes in the sources
docs/                   the built site (committed, so Pages can serve it as-is)
```

## Rebuilding

```sh
python3 book/build.py            # rebuild pages (cached audio is reused)
python3 book/build.py --audio    # also synthesise any narration whose text changed
```

`--audio` needs `pip install kokoro-onnx soundfile`, `ffmpeg`, and the model files `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the [kokoro-onnx releases](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0) in `$KOKORO_DIR`. Clips are cached by a hash of their text, so editing one paragraph re-renders only that clip. A clip that has no audio file falls back to the device voice.

## Publishing on GitHub Pages

Go to **Settings → Pages → Build and deployment**. Set **Source: Deploy from a branch**, pick the branch, and set the folder to **`/docs`**. The site is static (there's a `.nojekyll` file), so no build step runs on GitHub.
