Next, we will see that a set is Lebesgue measurable iff it can be approximated by the outside by open sets in the following sense:

The following theorem gives another characterization of Lebesgue measurable sets as those that can be "squeezed" between open and closed sets.

A set $E\subseteq\R^N$ is Lebesgue measurable if and only if for every $\eps\gt0$ there exist an open set $U$ and a closed set $F$ such that $$\boxed{F\subset E\subset U\quad\text{and}\quad\mathcal L^N(U\setminus F)\lt\eps.}\tag{6.13}$$ If, in addition, $\mathcal L^N(E)\lt+\infty$ then $F$ may be chosen to be compact.

[$\Rightarrow$] Assume that $E$ is Lebesgue measurable. Then $E^c$ is Lebesgue measurable, and by Thm 6.14 there exist open sets $U\supset E$ and $H\supset(\R^N\setminus E)$ s.t. $$\mathcal L^N(U\setminus E)\lt\frac\eps2,\quad\mathcal L^N(H\setminus E^c)\lt\frac\eps2.$$

Setting $F := \R^N\setminus H$, then $F$ is closed, $F\subset E\subset U$, and $$\mathcal L^N(U\setminus F)\le\mathcal L^N(U\setminus E)+\mathcal L^N(E\setminus F) = \mathcal L^N(U\setminus E)+\mathcal L^N(H\setminus E^c)\lt\eps.$$$U\setminus F = (U\setminus E)\cup(E\setminus F)$ since $F\subseteq E\subseteq U$. And $E\setminus F = E\cap H = H\setminus E^c$: points of $E$ that are in $H$ (not in $F = H^c$).

[$\Leftarrow$] Assume that $E$ satisfies (6.13). Given $\eps\gt0$, find $U$ open, $F$ closed such that $F\subset E\subset U$ and $\mathcal L^N(U\setminus F)\lt\eps$. 7. Completion of a σ-algebra w.r.t. a measure

Let $(X,\M,\mu)$ be a measure space, and let $$\mathcal N := \{A\subseteq X : \exists H\in\M\text{ with }A\subseteq H\text{ and }\mu(H) = 0\}.$$ … the set of all $\mu$-null subsets of $X$.

Recall (Def 3.8) that $\M$ is said to be complete wrt $\mu$ if $\mathcal N\subseteq\M$.

Recall also that by Carathéodory Thm 4.10, the σ-algebra $\M^*$ constructed via an outer measure $\ms$ is complete.

The completion $\M_\mu$ of $\M$ with respect to $\mu$ is defined as $$\M_\mu := \{B\cup A : B\in\M,\ A\in\mathcal N\}.$$

The Lebesgue σ-algebra $\mathcal L(\R^N)$ is the completion of the Borel σ-algebra $\B(\R^N)$ with respect to $\mathcal L^N$.

8. Measurable Functions

Let $(X,\M)$ and $(Y,\mathcal N)$ be measurable spaces. A function $f:X\to Y$ is said to be measurable if $f^{-1}(F)\in\M$ for every set $F\in\mathcal N$.

Let $(X,\M)$ be a measurable space, and let $Y$ be a nonempty set. Let $f:X\to Y$. Then $\mathcal N' := \{F\subseteq Y : f^{-1}(F)\in\M\}$ is a σ-algebra.

clearly $f^{-1}(\emptyset_Y) = \emptyset_X$, and so $\emptyset\in\mathcal N'$.

Let $F\in\mathcal N'$. Then $f^{-1}(Y\setminus F) = f^{-1}(Y)\setminus f^{-1}(F) = X\setminus f^{-1}(F)\in\M$$f(x)\notin F$ iff $x\notin f^{-1}(F)$; and $f^{-1}(Y) = X$. Complement of a measurable set. and so $Y\setminus F\in\mathcal N'$.

Finally, if $F_n\in\mathcal N'$ then $f^{-1}\big(\bigcup_{n=1}^\infty F_n\big) = \bigcup_{n=1}^\infty f^{-1}(F_n)\in\M$,$f(x)$ is in some $F_n$ iff $x$ is in some $f^{-1}(F_n)$. Countable union of measurable sets. and we conclude that $\bigcup_{n=1}^\infty F_n\in\mathcal N'$. ■
