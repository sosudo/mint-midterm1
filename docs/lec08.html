So let $E\subseteq g(\mathfrak C)$ be a non-measurable set.

Fact #2 In general, the image of a Borel set under a continuous function is not a Borel set, and the image of a Lebesgue set under a continuous function may not be measurable

E.g., there exists $E\subseteq\R$ Lebesgue measurable s.t. $E+E$ is not Lebesgue measurable.

However, if $f:I\to\R$ is continuous, $I\subseteq\R$ interval, $E\subset I$ Borel $\Rightarrow f(E)$ is Lebesgue measurable.

This can be generalized as follows: let $X$ be a complete, separable metric space, $f:X\to\R$ continuous. If $B\subseteq X$ is a Borel set then $f(B)\subset\R$ is Lebesgue measurable (but not necessarily Borel).

Let $I\subseteq\R$ be an interval and let $h:I\to\R$ be a continuous function.

claim if $B\subseteq\R$ is a Borel set, then $h^{-1}(B)$ is a Borel set [see Remark 8.4 (vi)]

Define $\M := \{E\subseteq\R : h^{-1}(E) \text{ is a Borel set}\}$

Since $h$ is continuous, if $U\subseteq\R$ is open then $h^{-1}(U)$ is relatively open ($h^{-1}(U) = V\cap I$ for some open set $V$, in case $I$ is not open) and thus $U\in\M$. (4.4)Continuity is exactly: preimages of open sets are (relatively) open. And $V\cap I$ is Borel: $V$ is open, $I$ is an interval (Borel), and Borel sets are closed under intersection.

Now $\M$ is a σ-algebra, because if $E\in\M$ then $h^{-1}(\R\setminus E) = I\setminus h^{-1}(E)$ still a Borel set, and if $E_n\in\M$ then $h^{-1}\big(\bigcup_{n=1}^\infty E_n\big) = \bigcup_{n=1}^\infty h^{-1}(E_n)$ still a Borel set.Preimages respect set operations: $x\in h^{-1}(\R\setminus E)$ iff $h(x)\notin E$ iff $x\notin h^{-1}(E)$ (for $x\in I$); and $h(x)\in\bigcup E_n$ iff $h(x)\in E_n$ for some $n$. Also $h^{-1}(\emptyset) = \emptyset$ is Borel. (Images do not respect complements or intersections — that's why images can fail where preimages succeed.)

So $\{\text{open sets of }\R\}\subset\M$ by (4.4), therefore $\B(\R)\subset\M$ (σ-algebra),$\B(\R)$ is the smallest σ-algebra containing the open sets, and $\M$ is one such σ-algebra. and this proves the claim.

Note that this continues to hold for a function $h:B\to Y$, continuous, $B\subseteq X$ Borel set, $X$ and $Y$ topological spaces.

5. Uniqueness

If $\mu$ is a measure on $(\R^N,\mathcal L(\R^N))$ (or $(\R^N,\B(\R^N))$) and $\mu(R) = \ell(R)$ $\forall$ rectangle $R$ then $\mu(A) = \mathcal L^N(A)$ for all $A\in\mathcal L(\R^N)$ (or $A\in\B(\R^N)$). [compare with Proposition 2.14]

step 1 We prove that $\mu\le\mathcal L^N$.

Let $A\in\mathcal L(\R^N)$, and let $A\subseteq\bigcup_{n=1}^\infty R_n$, $R_n$ rectangles.

Then $$\mu(A)\underset{\text{monotonicity + subadditivity}}{\le}\sum_{n=1}^\infty\mu(R_n) = \sum_{n=1}^\infty\mathcal L^N(R_n) = \sum_{n=1}^\infty\ell(R_n)\quad\text{(Prop 2.11)}$$$\mu$ is a measure, so it's monotone (Prop 4.3) and countably subadditive (Prop 4.5); rectangles are Borel so $\mu(R_n)$ makes sense. Then the hypothesis $\mu(R) = \ell(R)$, and Prop 2.11 for $\mathcal L^N(R_n) = \ell(R_n)$.

and taking the infimum over all such coverings, we get $$\mu(A)\le(\mathcal L^N)^*(A) = \mathcal L^N(A).$$

step 2 We prove that $\mathcal L^N\le\mu$ on bounded sets

Let $A\in\mathcal L(\R^N)$ be bounded, say $A\subseteq R$ some rectangle $R$.

Then by step 1 $$\mu(R\setminus A)\le\mathcal L^N(R\setminus A)\Leftrightarrow\mu(R)-\mu(A)\le\underbrace{\mathcal L^N(R)}_{=\mu(R)}-\mathcal L^N(A)$$Prop 4.3 (ii) on both sides — allowed because $\mu(A)\le\mu(R) = \ell(R)\lt\infty$ and $\mathcal L^N(A)\le\ell(R)\lt\infty$. Then cancel the equal finite numbers $\mu(R) = \ell(R) = \mathcal L^N(R)$.

and so $\mathcal L^N(A)\le\mu(A)$.

step 3 For arbitrary $A\in\mathcal L(\R^N)$, write $A = \bigcup_{n=1}^\infty A\cap(-n,n)^N$.

By Proposition 4.6 we have $$\mu(A) = \lim_{n\to+\infty}\mu\big(A\cap(-n,n)^N\big)\underset{\text{(step 2)}}{=}\lim_{n\to+\infty}\mathcal L^N\big(A\cap(-n,n)^N\big) = \mathcal L^N(A).\ \blacksquare$$The sets $A\cap(-n,n)^N$ increase with $n$ and their union is $A$ (every point lies in some cube), so continuity from below applies to both $\mu$ and $\mathcal L^N$. In between, each set is bounded, so step 1 + step 2 give $\mu = \mathcal L^N$ on it.

Now in an abstract setting… Let $X$ be a nonempty set, let $\M$ be a σ-algebra on $X$, and let $\mathcal E\subseteq\M$. Let $\mu,\nu$ be measures on $(X,\M)$ such that $\mu(X) = \nu(X)\lt+\infty$ and $\mu = \nu$ on $\mathcal E$.

Is it true that $\mu = \nu$ on $\sigma(\mathcal E)$? (5.1)

The answer, in general, is No!

Consider $\mathcal E := \{A,B\}$ with $\mu(A) = \nu(A)$, $\mu(B) = \nu(B)$ we could have $\mu(A\cap B)\ne\nu(A\cap B)$.

(5.1) holds if $\mathcal E$ is closed w.r.t. finite intersections.

Let $\mathcal R := \{A\in\M : \nu(A) = \mu(A)\}$.

Clearly $\mathcal E\subseteq\mathcal R$, and if $\mathcal R$ is a σ-algebra then $\sigma(\mathcal E)\subseteq\mathcal R$, proving (5.1).

(i) $\emptyset\in\mathcal R$ because $\nu(\emptyset) = 0 = \mu(\emptyset)$.

(ii) If $A\in\mathcal R$ then $\mu(X\setminus A) = \mu(X)-\mu(A) = \nu(X)-\nu(A) = \nu(X\setminus A)$Prop 4.3 (ii), allowed since $\mu(A)\le\mu(X)\lt\infty$ (and the same for $\nu$). The middle equality uses $\mu(X) = \nu(X)$ and $A\in\mathcal R$. This is why we need the total masses to be finite and equal. so $X\setminus A\in\mathcal R$. (5.2) $\mu(X) = \nu(X)\lt+\infty$

(iii) If $A_n\in\mathcal R$ and $A_n\subseteq A_{n+1}$, $n\in\N$, then by Proposition 4.6 $$\mu\Big(\bigcup_{n=1}^\infty A_n\Big) = \lim_{n\to+\infty}\mu(A_n) = \lim_{n\to+\infty}\nu(A_n) = \nu\Big(\bigcup_{n=1}^\infty A_n\Big),$$Continuity from below for both measures, and term-by-term agreement $\mu(A_n) = \nu(A_n)$. and so $\bigcup_{n=1}^\infty A_n\in\mathcal R$.

So the proof of Prop 5.2 actually follows from a more general context

We say that $\Pi\subseteq\mathcal P(X)$ is a π-system if

  1. $\Pi\ne\emptyset$,
  2. $A,B\in\Pi\Rightarrow A\cap B\in\Pi$.

We say that $\Lambda\subseteq\mathcal P(X)$ is a λ-system if

  1. $X\in\Lambda$,
  2. $A,B\in\Lambda$, $A\subseteq B\Rightarrow B\setminus A\in\Lambda$,
  3. $\{A_n\}\subseteq\Lambda$, $A_n\subseteq A_{n+1}\Rightarrow\bigcup_{n=1}^\infty A_n\in\Lambda$.

N.B. σ-algebras are both π-systems and λ-systems, and conversely see Rmk 5.7 (ii)

If $\Pi$ is a π-system, and $\Lambda$ is a λ-system, then $$\boxed{\Pi\subseteq\Lambda\Rightarrow\sigma(\Pi)\subseteq\Lambda.}$$

We can now reformulate Prop 5.2 as

If $\mu,\nu$ are finite measures that agree on a $\Pi$ (π-system) and $X\in\Pi$, then $\mu = \nu$ on $\sigma(\Pi)$.
