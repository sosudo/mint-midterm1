Let $\Q\cap[0,1] = \{r_1, r_2,\dots,r_n,\dots\}$. Let $$f_k(x) := \begin{cases}1 & x\in\{r_1,\dots,r_k\},\\ 0 & \text{—}.\end{cases}$$

Then $f_k$ is Riemann integrable, with $\int_0^1 f_k = 0$.Lower sums: every interval of a partition contains points other than $r_1,\dots,r_k$, where $f_k = 0$, so $\inf f_k = 0$ on every interval and $L(f_k,P) = 0$ for all $P$.Upper sums: given $\eps$, choose a partition in which each of the $k$ points $r_i$ lies in intervals of total length $\lt \eps$ (each $r_i$ touches at most two intervals, so make those intervals shorter than $\eps/(2k)$). Only those intervals have $\sup f_k = 1$, so $U(f_k,P) \lt \eps$. Hence $0 \le U(f_k,[0,1]) \lt \eps$ for all $\eps$, and lower $=$ upper $= 0$. However, $f_k\to f$ pointwise, $f(x) = \begin{cases}1 & x\in\Q\cap[0,1],\\ 0 & \text{—},\end{cases}$If $x$ is irrational, $f_k(x) = 0$ for every $k$, which equals $f(x) = 0$. If $x$ is rational, then $x = r_m$ for some $m$ (the list enumerates all of $\Q\cap[0,1]$), so $f_k(x) = 1 = f(x)$ for all $k\ge m$. Either way the sequence is eventually equal to $f(x)$. and thus function is not Riemann integrable (see Example 1.12).

But the following is a positive result:

Let $f_n:[a,b]\to\R$ be Riemann integrable functions with $|f_n(x)|\le M$ $\forall n\in\N$, $x\in[a,b]$. Let $f:[a,b]\to\R$ be the pointwise limit, $$f_n(x)\underset{n\to+\infty}{\longrightarrow} f(x)\quad\forall x\in[a,b].$$ (If) $f$ is Riemann integrable then $$\int_a^b f = \lim_{n\to+\infty}\int_a^b f_n \quad\text{(interchange } \textstyle\int \text{ with } \lim\text{)}.$$

Note the (If)!

We'll give a proof later on using measure theory.

Further, Prop 1.16 also ok if $f_n\to f$ uniformly. (don't need the (If)) (see Rmk 10.11)

The boundedness of $\{f_n\}$ is important.

Riemann vs. Lebesgue: the plan

Riemann integral: partition the domain (count sequentially) then draw rectangles to approximate area under the curve.

Lebesgue integral: partition the range — look @ points with "same value" of $f$ and aggregate them (stack and sort)

Goal:

  • $s: X\to\R$ (simple function) $\displaystyle s = \sum_{i=1}^N a_i\chi_{A_i}$, $A_i$ "nice" sets, $A_i = s^{-1}(\{a_i\})$ $$\int_X s\,d\mu := \sum_{i=1}^N a_i\,\mu(A_i)$$ ↑ need the concept of measure
  • $f\ge0$, define $\displaystyle\int_X f\,d\mu := \sup_{s\le f}\int_X s\,d\mu$

2. Outer Measures

Consider a set $X$ (e.g., $X = \R^N$, $X = I$ with $I = [a,b]\subseteq\R$).

Goal: to "measure" an arbitrary set $E\subseteq X$.

Idea: approximate $E$ with unions of "nice" sets (elementary sets) to which we know how to assign a measure.

E.g., in $\R^N$ use cubes, rectangles, balls; in $\R$ use intervals $(a,b), [a,b), (a,b], [a,b]$ ("building blocks").

Let $\mathcal E\subset\mathcal P(X)$ be a family of elementary sets, with $\emptyset\in\mathcal E$ and $X = \bigcup_{n=1}^\infty X_n$ for some $X_n\in\mathcal E$.

Let $\rho:\mathcal E\to[0,+\infty]$ s.t. $\rho(\emptyset) = 0$. (elementary measure)

Define $\ms:\mathcal P(X)\to[0,+\infty]$ by $$\ms(E) := \inf\Big\{\sum_{n=1}^\infty \rho(E_n) : E_n\in\mathcal E\ \forall n\in\N,\ E\subseteq\bigcup_{n=1}^\infty E_n\Big\}. \tag{2.1}$$

If $I\subseteq\R$ is an interval, define $\ell(I) := \sup I - \inf I$ $\big(= \rho(I)\big)$ (so that $\ell(I) = \ell(\mathring I) = \ell(\overline I)$).

A rectangle in $\R^N$ is a set of the form $$R := I_1\times\dots\times I_N,\quad I_i\subset\R \text{ intervals, with } \ell(R) := \prod_{i=1}^N \ell(I_i).$$

N.B. $\emptyset = \prod_{i=1}^N (a,a)$ so $\ell(\emptyset) = 0$

$\forall a\in\R^N$ $\ell(R) = \ell(a+R)$ for all rectangle $R\subseteq\R^N$ (translation invariance)

Lebesgue Outer Measure: Let $\mathcal E$ be the family of rectangles (elementary sets), with $\emptyset\in\mathcal E$. Let $E\subseteq\R^N$. Define $$(\mathcal L^N)^*(E) := \inf\Big\{\sum_{n=1}^\infty \ell(R_n) : E\subseteq\bigcup_{n=1}^\infty R_n,\ R_n \text{ rectangle}\Big\}.$$ … $N$-dimensional Lebesgue outer measure.

Let $I\subseteq\R$ be an open interval and let $f:I\to\R$ be an increasing function.

Let $\mathcal E$ be the family of all intervals $(a,b]$, $a,b\in I$, $a\le b$. Set $\rho:\mathcal E\to[0,+\infty)$ to be $$\rho\big((a,b]\big) := f(b) - f(a)\quad(\ge0).$$

Given $E\subseteq I$, the Lebesgue–Stieltjes outer measure of $E$ generated by $f$ is $$\mu_f^*(E) := \inf\Big\{\sum_{n=1}^\infty \underbrace{\big(f(b_n) - f(a_n)\big)}_{\rho((a_n,b_n])} : a_n,b_n\in I,\ a_n\le b_n,\ E\subseteq\bigcup_{n=1}^\infty (a_n,b_n]\Big\}.$$

Let $0\le s\lt+\infty$. For $0\lt\delta\le+\infty$ consider the family $$\mathcal E_\delta := \{F\subseteq\R^N : \operatorname{diam} F\lt\delta\}.$$ Here, $\operatorname{diam} F := \sup\{\|x-y\| : x,y\in F\}$, $\|\cdot\|$ Euclidean norm.

Consider the elementary measure $$\rho_s(F) := \alpha_s\Big(\frac{\operatorname{diam} F}{2}\Big)^s,\quad F\in\mathcal E_\delta$$ where $\alpha_s\gt0$ is a constant.

If $E\subseteq\R^N$ define $$\mathcal H^s_\delta(E) := \inf\Big\{\sum_{n=1}^\infty \alpha_s\Big(\frac{\operatorname{diam}E_n}{2}\Big)^s : E_n\in\mathcal E_\delta,\ E\subseteq\bigcup_{n=1}^\infty E_n\Big\}.$$

If $s = 0$ then sum only over those $E_n\ne\emptyset$, with $\big(\frac{\operatorname{diam}E_n}{2}\big)^0 := 1$ even if $\operatorname{diam}E_n = 0$.

Recognizing that $\delta\mapsto\mathcal H^s_\delta(E)$ is decreasing (because $\delta'\lt\delta \Rightarrow \mathcal E_{\delta'}\subseteq\mathcal E_\delta \Rightarrow \inf_\delta \le \inf_{\delta'}$)A set of diameter $\lt\delta'$ certainly has diameter $\lt\delta$, so every cover admissible at scale $\delta'$ is admissible at scale $\delta$. An infimum over a bigger collection of covers is smaller or equal: $\mathcal H^s_\delta(E)\le\mathcal H^s_{\delta'}(E)$. So shrinking $\delta$ can only increase $\mathcal H^s_\delta(E)$ — finer covers are forced to follow the shape of $E$ more closely. we set $$\boxed{\mathcal H^s(E) := \lim_{\delta\to0^+}\mathcal H^s_\delta(E) = \sup_{\delta\gt0}\mathcal H^s_\delta(E)}$$ … $s$-dimensional Hausdorff outer measure of $E$.

Often $\alpha_s$ is taken to be $1$. Here, we take $$\alpha_s := \frac{\pi^{s/2}}{\Gamma\big(\frac s2 + 1\big)}$$ where $\Gamma$ is the Euler-Gamma function $$\Gamma(t) := \int_0^\infty e^{-x}x^{t-1}\,dx,\quad 0\lt t\lt\infty.$$ Then $\Gamma(n) = (n-1)!$ $\forall n\in\N$ and $$\rho_N(B(0,1)) = \alpha_N = (\mathcal L^N)^*(B(0,1))\quad\big(= \mathcal L^N(B(0,1)) \text{ when we'll define the } N\text{-dim. Lebesgue meas.}\big)$$ (see Example 4.10(i))

Let $X$ be a nonempty set. A map $\ms:\mathcal P(X)\to[0,+\infty]$ is an outer measure if

  1. $\ms(\emptyset) = 0$;
  2. [Monotonicity] $E\subseteq F\subseteq X \Rightarrow \ms(E)\le\ms(F)$
  3. [Countable Subadditive] $\displaystyle\ms\Big(\bigcup_{n=1}^\infty E_n\Big)\le\sum_{n=1}^\infty\ms(E_n)$ for all $\{E_n\}\subseteq\mathcal P(X)$.

We prove that the function $\ms$ defined in (2.1) is an outer measure.

Let $X$ be a nonempty set, let $\mathcal E\subset\mathcal P(X)$ s.t. $\emptyset\in\mathcal E$ and there exist $X_n\in\mathcal E$, $n\in\N$, such that $X = \bigcup_{n=1}^\infty X_n$. Let $\rho:\mathcal E\to[0,+\infty]$ be such that $\rho(\emptyset) = 0$. Then $\ms$ defined in (2.1) is an outer measure, and $$\boxed{\ms(E)\le\rho(E)}\quad\text{for all } E\in\mathcal E. \tag{2.2}$$

(i) claim $\ms(\emptyset) = 0$.
This is clear since $\emptyset\in\mathcal E$ and $\rho(\emptyset) = 0$.The sequence $E_n = \emptyset$ for all $n$ is an admissible cover of $\emptyset$ (all $E_n\in\mathcal E$, and $\emptyset\subseteq\bigcup E_n$), with cost $\sum\rho(\emptyset) = 0$. So the infimum is $\le 0$; and it's $\ge0$ since $\rho\ge0$.

(ii) Let $E\subseteq F\subseteq X$. claim $\ms(E)\le\ms(F)$.
Let $F\subseteq\bigcup_{n=1}^\infty F_n$, $F_n\in\mathcal E$. Then $E\subseteq\bigcup_{n=1}^\infty F_n$, so $$\ms(E)\le\sum_{n=1}^\infty\rho(F_n).$$$E\subseteq F\subseteq\bigcup F_n$, so $\{F_n\}$ is one of the admissible covers in the definition of $\ms(E)$. An infimum is $\le$ each element of the set, in particular $\le$ the cost $\sum\rho(F_n)$ of this cover.

Taking the infimum over the family $\{F_n\}$, we conclude that $$\ms(E)\le\ms(F).$$$\ms(E)$ is a lower bound for the costs of all covers of $F$ (that's what the previous line showed, since $\{F_n\}$ was arbitrary). The greatest lower bound of those costs is $\ms(F)$, so $\ms(E)\le\ms(F)$.

(iii) Let $E_n\subseteq X$, $n\in\N$. claim $\displaystyle\ms\Big(\bigcup_{n=1}^\infty E_n\Big)\le\sum_{n=1}^\infty\ms(E_n)$.

Fix $\eps\gt0$, and for all $n\in\N$ find $\{E_{n,k}\}_{k\in\N}\subseteq\mathcal E$ s.t. $$\sum_{k=1}^\infty\rho(E_{n,k})\le\ms(E_n) + \frac{\eps}{2^n},\qquad E_n\subseteq\bigcup_{k=1}^\infty E_{n,k}.$$We may assume $\ms(E_n)\lt\infty$ for every $n$ (otherwise the right side of the claim is $+\infty$ and there is nothing to prove). Then $\ms(E_n)+\eps/2^n$ is strictly bigger than the infimum $\ms(E_n)$, so it is not a lower bound for the costs of covers of $E_n$: some cover $\{E_{n,k}\}_k$ costs less. (Here we use the hypothesis that covers exist at all: $X = \bigcup X_n$ covers everything.)The budget $\eps/2^n$ is chosen so that the errors over all $n$ add up to at most $\eps$.

Then $\displaystyle\bigcup_{n=1}^\infty E_n\subseteq\bigcup_{n=1}^\infty\bigcup_{k=1}^\infty E_{n,k}$Each $E_n$ is inside its own cover $\bigcup_k E_{n,k}$; take the union over $n$. The double family $\{E_{n,k}\}_{n,k\in\N}$ is countable ($\N\times\N$ is countable), so after enumerating it as a single sequence it is an admissible cover in (2.1)., hence

$$\ms\Big(\bigcup_{n=1}^\infty E_n\Big)\le\sum_{n=1}^\infty\sum_{k=1}^\infty\rho(E_{n,k})$$

$\ms$ of the union is the infimum over all covers; this particular double-indexed cover has cost $\sum_{n,k}\rho(E_{n,k})$. Since all terms are $\ge0$, the sum of a non-negative double series doesn't depend on the order of summation, so we may sum first over $k$, then over $n$.

$$\le\sum_{n=1}^\infty\Big[\ms(E_n) + \frac{\eps}{2^n}\Big] = \sum_{n=1}^\infty\ms(E_n) + \eps.$$

Apply the choice of the covers: the inner sum $\sum_k\rho(E_{n,k})$ is $\le\ms(E_n)+\eps/2^n$. Then split the sum and use the geometric series $\sum_{n\ge1}2^{-n} = 1$.

Let $\eps\to0^+$.The left side doesn't depend on $\eps$ and is $\le\sum\ms(E_n)+\eps$ for every $\eps\gt0$, hence $\le\sum\ms(E_n)$.

Finally, let $E\in\mathcal E$. claim $\ms(E)\le\rho(E)$.
This follows trivially from the fact that $\{E\}$ is a covering of $E$Take $E_1 = E$ and $E_n = \emptyset$ for $n\ge2$: all in $\mathcal E$, covering $E$, with cost $\rho(E)+0+0+\dots = \rho(E)$. The infimum is at most this.. ■

Question: When do we have equality in (2.2)?

E.g., would like to have $(\mathcal L^N)^*(R) = \ell(R)$, $R\subset\R^N$ rectangle.

Let $X$ be a nonempty set, let $\mathcal E\subseteq\mathcal P(X)$ s.t. $\emptyset\in\mathcal E$ and there exist $X_n\in\mathcal E$, $n\in\N$, s.t. $X = \bigcup_{n=1}^\infty X_n$. Let $\rho:\mathcal E\to[0,+\infty]$ s.t. $\rho(\emptyset) = 0$; and let $\ms:\mathcal P(X)\to[0,+\infty]$ be defined as in (2.1).

Then $\ms(E) = \rho(E)$ for every $E\in\mathcal E$ iff $\rho$ is countable subadditive, i.e., $$\rho(E)\le\sum_{n=1}^\infty\rho(E_n)$$ whenever $E, E_n\in\mathcal E$, $n\in\N$, and $E\subseteq\bigcup_{n=1}^\infty E_n$.

[$\Leftarrow$] Assume that $\rho$ is countable subadditive. Let $E, E_n\in\mathcal E$. Let $E\subseteq\bigcup_{n=1}^\infty E_n$, $n\in\N$. Then $$\rho(E)\le\sum_{n=1}^\infty\rho(E_n)$$ and taking the infimum over all such $\{E_n\}\subseteq\mathcal E$, we get $\rho(E)\le\ms(E)$.$\rho(E)$ is a lower bound for the cost of every admissible cover of $E$, so it is $\le$ the greatest lower bound, which is $\ms(E)$ by (2.1).

By (2.2) we have always $\ms(E)\le\rho(E)$, hence $\ms(E) = \rho(E)$.

When we introduced the Lebesgue outer measure in $\R^N$, we took as elementary sets rectangles $=$ products of intervals, and intervals could be open, closed, semi-open.

Since $\ell\big((a,b)\big) = \ell\big([a,b]\big) = \ell\big([a,b)\big) = \ell\big((a,b]\big)$, the outer-measure does not see the difference if we restrict the intervals to be only open, only closed, etc. Hence, the same applies to rectangles in $\R^N$.

Let $R$ be a rectangle in $\R^N$ (an elementary set, not nec. open or closed). Then $$\boxed{(\mathcal L^N)^*(R) = \ell(R).}$$

We already know that $(\mathcal L^N)^*(R)\le\ell(R)$ (see 2.2)Prop 2.7, inequality (2.2), applied with $\mathcal E$ = rectangles and $\rho = \ell$: the rectangle $R$ covers itself.

step 1 We claim that $$(\mathcal L^N)^*(R) = \inf\Big\{\sum_{n=1}^\infty\ell(R_n) : R\subseteq\bigcup_{n=1}^\infty R_n,\ R_n \textbf{ open} \text{ rectangles}\Big\} =: \mu^*(R).$$

Clearly $(\mathcal L^N)^*(R)\le\mu^*(R)$. (because we are restricting the admissible $R$'s on $(\mathcal L^N)^*$ to obtain $\mu^*$).Every cover by open rectangles is in particular a cover by rectangles. So the set of costs defining $\mu^*(R)$ is a subset of the set of costs defining $(\mathcal L^N)^*(R)$, and the infimum over a smaller set is larger or equal.
