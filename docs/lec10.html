claim If $E\in\M$ then $U_n\setminus E\in\M$.

Fix $\eps\gt0$ and find $C$ compact, $V$ open, with $$C\subset E\subset V\subset U_n,\qquad\ms(V\setminus C)\le\eps.\tag{6.1}$$

Then $U_n\setminus C$ is open, $U_n\setminus E\subset U_n\setminus C$$C$ is compact in a Hausdorff space, hence closed, so $U_n\setminus C = U_n\cap(X\setminus C)$ is open. And $C\subseteq E$ means removing $C$ removes less., and

$$\ms(U_n\setminus C) = \ms(U_n)-\ms(C)\ [\text{because }\ms\llcorner\B(X)\text{ is a measure and }\ms(C)\lt+\infty]\le\ms(U_n)-\ms(V)+\eps = \ms(U_n\setminus V)+\eps\le\ms(U_n\setminus E)+\eps.$$

Prop 4.3 (ii) for $C\subseteq U_n$. Then (6.1): $\ms(C)\ge\ms(V)-\eps$. Then Prop 4.3 (ii) backwards for $V\subseteq U_n$. Finally $U_n\setminus V\subseteq U_n\setminus E$ (monotonicity).

Thus, $U_n\setminus E$ is outer regular.

On the other hand, since $U_n$ is σ-compact there exists a compact set $K\subset U_n$ st. $$\ms(U_n)\le\ms(K)+\eps.\tag{6.2}$$As written next: $U_n$ is an increasing union of compacts $K_j$, so by continuity from below $\ms(K_j)\to\ms(U_n)\lt\infty$; take $K = K_j$ for $j$ large.

Indeed, write $U_n = \bigcup_{j=1}^\infty K_j$, $K_j\subseteq K_{j+1}$ compact sets, and since $\ms\llcorner\B(X)$ is a measure, by Thm 4.6 $\ms(U_n) = \lim_{j\to+\infty}\ms(K_j)$. Set $K := K_j$ for $j\gg1$.

Then $K\setminus V$ is compact, $K\setminus V\subset U_n\setminus E$$K\setminus V = K\cap(X\setminus V)$ is a closed subset of a compact set, hence compact. A point of $K\setminus V$ is in $U_n$ (as $K\subseteq U_n$) and not in $V\supseteq E$., and by (6.1)

$$\ms(U_n\setminus E)\le\ms\big((U_n\setminus V)\cup(V\setminus E)\big)\le\ms\big((U_n\setminus V)\cup(V\setminus C)\big)\underset{(6.1)}{\le}\ms(U_n\setminus V)+\eps = \ms\big((K\setminus V)\cup(U_n\setminus K)\big)+\eps\underset{(6.2)}{\le}\ms(K\setminus V)+2\eps.$$

$U_n\setminus E$ = (outside $V$) ∪ (inside $V$ but not $E$). Then $V\setminus E\subseteq V\setminus C$, subadditivity and (6.1). Then $U_n\setminus V$ splits into the part in $K$ and the part outside $K$; the latter has measure $\ms(U_n)-\ms(K)\le\eps$ by (6.2).

Thus shows that $U_n\setminus E$ is inner regular.

Step 2 Let $B\in\B(X)$. We claim that $B$ is outer regular.

Fix $\eps\gt0$. By step 1 there exists an open set $V_1\subset U_1$ such that $B\cap U_1\subset V_1$ and $\ms(V_1)\le\ms(B\cap U_1)+\frac\eps2$.

Inductively, assume that for $k = 1,\dots,n$, there exist open sets $V_k\subseteq U_k$ such that $B\cap U_k\subset V_k$, $V_1\subset V_2\subset\dots\subset V_n$ and $\ms(V_k)\le\ms(B\cap U_k)+\sum_{i=1}^k\frac\eps{2^i}$.

To construct $V_{n+1}$, by step 1 find an open set $V'_{n+1}\subset U_{n+1}$ such that $$(B\setminus U_n)\cap U_{n+1}\subset V'_{n+1}\quad\text{and}\quad\ms(V'_{n+1})\le\ms\big((B\setminus U_n)\cap U_{n+1}\big)+\frac\eps{2^{n+1}}.$$

Set $V_{n+1} := V_n\cup V'_{n+1}$. Then $$B\cap U_{n+1} = (B\cap U_n)\cup\big[(B\setminus U_n)\cap U_{n+1}\big]\subset V_n\cup V'_{n+1} = V_{n+1},$$ and

$$\ms(V_{n+1})\le\ms(V_n)+\ms(V'_{n+1})\le\ms(B\cap U_n)+\ms\big((B\setminus U_n)\cap U_{n+1}\big)+\sum_{i=1}^n\frac\eps{2^i}+\frac\eps{2^{n+1}} = \ms(B\cap U_{n+1})+\sum_{i=1}^{n+1}\frac\eps{2^i},$$

Subadditivity, the inductive hypothesis and the choice of $V'_{n+1}$. For the last equality: $B\cap U_n$ and $(B\setminus U_n)\cap U_{n+1}$ are disjoint Borel sets whose union is $B\cap U_{n+1}$ (since $U_n\subseteq U_{n+1}$), so additivity of the measure $\ms\llcorner\B(X)$ combines them.

where we used the additivity of the measure $\ms\llcorner\B(X)$ [Carathéodory Thm 4.9].

Observe that $B\subseteq\bigcup_{n=1}^\infty V_n$, an open set, and

$$\ms\Big(\bigcup_{n=1}^\infty V_n\Big) = \lim_{n\to+\infty}\ms(V_n)\ (\text{Thm 4.6})\le\lim_{n\to\infty}\ms(B\cap U_n)+\eps\le\ms(B)+\eps.$$

$B = \bigcup_n(B\cap U_n)\subseteq\bigcup V_n$ because the $U_n\supseteq K_n$ exhaust $X$. The $V_n$ are open (Borel) and increasing: continuity from below. Then the bound with $\sum\eps/2^i\le\eps$, and monotonicity $\ms(B\cap U_n)\le\ms(B)$.

Step 3 Let $B\in\B(X)$. We claim that $B$ is inner regular. Let $t\lt\ms(B)$ and choose $n\gg1$ so that $\ms(B\cap U_n)\gt t$.$B\cap U_n$ increases to $B$ (Borel sets), so $\ms(B\cap U_n)\to\ms(B)$ by continuity from below; eventually it exceeds $t$. "Here we used the fact that $\ms$ is a Borel o.m."

By Step 1 we can find a compact set $C\subset B\cap U_n$ such that $\ms(C)\gt t$. This shows that $\ms(B)$ can be approximated by the outer measure of compact subset of $B$. Here we used the fact that $\ms$ is a Borel o.m., hence $\ms(B) = \lim_{n\to+\infty}\ms(B\cap U_n)$.

Step 4 Assume that $\ms$ is Borel regular, i.e., it is a Borel outer measure ($\B(X)\subset\M^*$), and for all $E\subset X$ $\exists B\in\B(X)$ such that $E\subset B$, $\ms(E) = \ms(B)$.

We claim that $\ms$ is a Radon measure, i.e.,

  1. it is a Borel outer measure;
  2. $\ms(K)\lt+\infty$ for every compact set $K\subset X$, which holds by assumption;
  3. every open set is inner regular, which holds by step 3;
  4. every set $E\subset X$ is outer regular.

Indeed, let $B\in\B(X)$ be such that $E\subset B$, $\ms(E) = \ms(B)$. By Step 2 $B$ is outer regular, so given $\eps\gt0$ there exists an open set $V\subset X$, $B\subset V$ and $\ms(V)\le\ms(B)+\eps$.

Hence $E\subset V$, and $\ms(V)\le\ms(B)+\eps = \ms(E)+\eps$.$E\subseteq B\subseteq V$, and the Borel hull has the same outer measure as $E$. So outer regularity passes from the Borel hull to the arbitrary set $E$. ■

By Def 6.7, if $\ms:\mathcal P(X)\to[0,+\infty]$ is a Radon outer measure, then every set $E\subset X$ is outer regular. In general, we don't have that every set is inner regular, but the following holds:

Let $X$ be a topological space, and let $\ms:\mathcal P(X)\to[0,+\infty]$ be a Radon measure. Then every σ-finite $\ms$-measurable set is inner regular.

Let $E\subset X$ be a $\ms$-measurable set, σ-finite.

Step 1 Assume first that $\ms(E)\lt+\infty$.

Since $E$ is outer regular, for $\eps\gt0$ there exists an open set $V\supset E$ such that $\ms(V)\lt\ms(E)+\eps$.

By the inner regularity of open sets, there exists a compact set $K\subset V$ such that $\ms(V)\lt\ms(K)+\eps$.

Since $E$ is $\ms$-measurable, we have $$\underbrace{\ms(E\cap V)}_{\ms(E)}+\ms(V\setminus E) = \ms(V)\lt\ms(E)+\eps,$$Measurability of $E$ (Def 3.1) tested on $V$; $E\cap V = E$ because $E\subseteq V$. and so $\ms(V\setminus E)\lt\eps$. (used $\ms(E)\lt+\infty$)Subtract the finite number $\ms(E)$ from both sides.

By outer regularity, there exists an open set $U\supset V\setminus E$ st. $\ms(U)\lt\eps$. $(*)$

The compact set $C := K\setminus U$ is contained in $E$$C$ is a closed subset ($K\cap(X\setminus U)$) of the compact $K$, hence compact. A point of $K$ is in $V$; if it's not in $U\supseteq V\setminus E$, it can't be in $V\setminus E$, so it's in $E$., and since $U$ is $\ms$-measurable,

$$\ms(C) = \ms(K\setminus U) = \ms(K)-\ms(K\cap U)\gt\ms(V)-\eps-\ms(K\cap U)\ge\ms(V)-\eps-\ms(U)\underset{(*)}{\gt}\ms(V)-2\eps\underset{(E\subset V)}{\ge}\ms(E)-2\eps.$$

Hence $E$ is inner regular.

We will see that (6.3) holds for every Lebesgue measurable set $E$, and every set is outer regular, i.e., (6.5).

If $E\subseteq\R^N$ then $$(\mathcal L^N)^*(E) = \inf\{\mathcal L^N(U) : E\subset U,\ U\text{ open}\}\ (\text{outer-regularity}),$$ and if $E$ is Lebesgue measurable, then $$\mathcal L^N(E) = \sup\{\mathcal L^N(K) : K\subset E,\ K\text{ compact}\}\ (\text{inner-regularity})$$ (i.e., (6.6)). In particular, $(\mathcal L^N)^*$ is a Radon measure.

Step 1 Let $E\subseteq\R^N$. We prove that $$(\mathcal L^N)^*(E) = \inf\{\mathcal L^N(U) : E\subset U,\ U\text{ open}\}.$$

If $(\mathcal L^N)^*(E) = +\infty$ then this is clearly true, take $U := \R^N$.

Suppose that $(\mathcal L^N)^*(E)\lt+\infty$. By monotonicity, $(\mathcal L^N)^*(E)\le\inf\{\mathcal L^N(U) : E\subset U,\ U\text{ open}\}$Each admissible $U$ contains $E$, so $(\mathcal L^N)^*(E)\le\mathcal L^N(U)$; take the inf., so we show the reverse inequality, $$(\mathcal L^N)^*(E)\ge\inf\{\mathcal L^N(U) : E\subset U,\ U\text{ open}\}.\tag{6.7}$$

Let $\eps\gt0$, and find a covering of $E$, $\{R_i : i\in\N\}$, by rectangles such that $$\sum_{i=1}^\infty\mathcal L^N(R_i)\le(\mathcal L^N)^*(E)+\frac\eps2.$$

Let $S_i$ be a rectangle whose interior $\mathring S_i$ contains $R_i$, and $$\mathcal L^N(S_i)\le\mathcal L^N(R_i)+\frac\eps{2^{i+1}}.$$

Then the collection of open rectangles $\{\mathring S_i : i\in\N\}$ covers $E$ and with $U := \bigcup_{i=1}^\infty\mathring S_i$, we have $$\mathcal L^N(U)\le\sum_{i=1}^\infty\mathcal L^N(S_i)\le\sum_{i=1}^\infty\mathcal L^N(R_i)+\frac\eps2\le(\mathcal L^N)^*(E)+\eps,$$Subadditivity and monotonicity ($\mathring S_i\subseteq S_i$), then the dilation bound with $\sum\eps/2^{i+1} = \eps/2$, then the choice of cover. $U$ is a union of open sets, hence open, and contains $E$. and this proves (6.7).
