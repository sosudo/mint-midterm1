Recap in class: Props 4.6 and 4.7 (measure of increasing unions / decreasing sequences)

Proposition 4.6 [Measure of an Increasing Function] $(X,\M,\mu)$ measure space, $E_n\in\M$, $n\in\N$, $E_n\subseteq E_{n+1}$, $n\in\N$ then $\mu\big(\bigcup_{n=1}^\infty E_n\big) = \lim_{n\to+\infty}\mu(E_n)$. [$\subset$, $\subsetneq$, $\subseteq$]

Proof If $\exists n\in\N$ s.t. $\mu(E_n) = +\infty$ then monotonicity $\Rightarrow$ $\forall m\ge n$ $\mu(E_m)\ge\mu(E_n) = +\infty$ and $\mu\big(\bigcup_{m=1}^\infty E_m\big)\ge\mu(E_n) = +\infty$ done! ($\infty = \infty$)

Assume $\forall n\in\N$ $\mu(E_n)\lt+\infty$. $\bigcup_{n=1}^\infty E_n = \bigcup_{n=1}^\infty(E_n\setminus E_{n-1})$, $E_0 := \emptyset$ $$\mu\Big(\bigcup_{n=1}^\infty E_n\Big) = \mu\Big(\bigcup_{n=1}^\infty(E_n\setminus E_{n-1})\Big) = \sum_{n=1}^\infty\mu(E_n\setminus E_{n-1}) = \lim_{k\to+\infty}\sum_{n=1}^k\mu(E_n\setminus E_{n-1})$$

$$\underset{(4.3\,(ii))}{=}\lim_{k\to+\infty}\sum_{n=1}^k\big[\mu(E_n)-\mu(E_{n-1})\big] = \lim_{k\to+\infty}\mu(E_k).\ \blacksquare$$

Proposition 4.7 [Measure of a Decreasing Sequence] $(X,\M,\mu)$ measure space, $E_n\in\M$, $E_n\supseteq E_{n+1}$ $\forall n\in\N$, $\mu(E_1)\lt+\infty$. Then $\mu\big(\bigcap_{n=1}^\infty E_n\big) = \lim_{n\to+\infty}\mu(E_n)$.

Proof De Morgan's law: $E_1\setminus\bigcap_{n=1}^\infty E_n = \bigcup_{n=1}^\infty(E_1\setminus E_n)$, $\emptyset = E_1\setminus E_1\subset E_1\setminus E_2\subset\dots\subset E_1\setminus E_n\subset\dots$

Prop 4.6 $\Rightarrow\mu\big(E_1\setminus\bigcap_{n=1}^\infty E_n\big) = \mu\big(\bigcup_{n=1}^\infty(E_1\setminus E_n)\big) = \lim_{n\to+\infty}\mu(E_1\setminus E_n)\underset{(4.3\,(ii))}{=}\lim_{n\to+\infty}\big[\cancel{\mu(E_1)}-\mu(E_n)\big]$ and the left side is $\cancel{\mu(E_1)}-\mu\big(\bigcap_{n=1}^\infty E_n\big)$

$\Rightarrow\mu\big(\bigcap_{n=1}^\infty E_n\big) = \lim_{n\to+\infty}\mu(E_n)$. ■

Def 4.8 Given a measure space $(X,\M,\mu)$, the measure $\mu$ is said complete if $\forall E\in\M$ with $\mu(E) = 0$ then $F\in\M$ $\forall F\subseteq E$.

$(X,\M,\mu)$ measure space, $E_n\in\M$, $\sum_{n=1}^\infty\mu(E_n)\lt+\infty$.

Then almost every $x\in X$ belongs to at most finitely many $E_n$'s, i.e. $$\mu\big(\{x\in X : x\in E_n \text{ for } \infty\text{'ly many } n\text{'s}\}\big) = 0.$$

$$\{x\in X : x\in E_n \text{ for } \infty\text{'ly many } n\text{'s}\} = \bigcap_{n=1}^\infty\bigcup_{k=n}^\infty E_k =: \boxed{\limsup_{n\to+\infty}E_n} =: E$$$x\in\bigcap_n\bigcup_{k\ge n}E_k$ means: for every $n$ there is some $k\ge n$ with $x\in E_k$. That says the indices $k$ with $x\in E_k$ are unbounded, i.e. infinitely many. Conversely, infinitely many indices means arbitrarily large ones. Also $E\in\M$: countable unions and intersections of measurable sets.

Suppose that $\mu(E) = \alpha\gt0$.

So $$0\lt\alpha = \mu(E) = \mu\Big(\bigcap_{n=1}^\infty\bigcup_{k=n}^\infty E_k\Big)\underset{\text{(monotonicity)}}{\le}\mu\Big(\bigcup_{k=n}^\infty E_k\Big)\quad\forall n\in\N$$An intersection is contained in each of the sets it intersects; here, in $\bigcup_{k\ge n}E_k$ for each fixed $n$. Then monotonicity (Prop 4.3 (i)). $$\underset{\text{(subadditivity)}}{\le}\sum_{k=n}^\infty\mu(E_k).$$Countable subadditivity, Prop 4.5.

Since $\sum_{n\ge1}\mu(E_n)\lt+\infty$ choose $n\gg1$ $\sum_{k=n}^\infty\mu(E_k)\lt\alpha/2$ ⚡For a convergent series, the tails $\sum_{k\ge n}$ tend to $0$ (they're the total minus the partial sums, which converge to the total). Then $\alpha\le\sum_{k\ge n}\mu(E_k)\lt\alpha/2$, impossible since $\alpha\gt0$. ■

Step 1 WTS that $\M^*$ is a σ-algebra (Def 3.4, (i)–(iii))

(i) $\emptyset\in\M^*$
let $F\subseteq X$ $\ms(F) = \underbrace{\ms(F\cap\emptyset)}_{\ms(\emptyset) = 0}+\underbrace{\ms(F\setminus\emptyset)}_{=\ms(F)}$ ok!$F\cap\emptyset = \emptyset$ has outer measure $0$ (Def 2.6 (i)), and $F\setminus\emptyset = F$. So the measurability identity reads $\ms(F) = 0 + \ms(F)$.

(ii) $E\in\M^*$. ? $X\setminus E\in\M^*$?

let $F\subseteq X$ $$\ms(F) = \ms(F\cap E)+\ms(F\setminus E) = \ms\big(F\setminus\underbrace{(X\setminus E)}\big)+\ms\big(F\cap\underbrace{(X\setminus E)}\big)$$First equality: $E$ is measurable. Second: set identities $F\cap E = F\setminus(X\setminus E)$ and $F\setminus E = F\cap(X\setminus E)$. Reading the result, it is exactly the measurability identity for the set $X\setminus E$ (with the two terms swapped). $\Rightarrow X\setminus E\in\M^*$.

(iii)′ claim $E_1,E_2\in\M^*\Rightarrow E_1\cup E_2\in\M^*$

[In Step 4 we extend to countable unions, i.e., (iii) … done!]

Fix $F\subseteq X$. $\ms(F) = \ms(F\cap E_1)+\ms(F\setminus E_1)$$E_1$ is measurable, test set $F$.

$\ms(F\setminus E_1) = \ms\big((F\setminus E_1)\cap E_2\big)+\ms\big((F\setminus E_1)\setminus E_2\big)$$E_2$ is measurable, now tested on the set $F\setminus E_1$. (Measurability must hold for every test set — this flexibility is what makes the proof work.)

Hence, $$\ms(F) = \ms(F\cap E_1)+\ms\big((F\setminus E_1)\cap E_2\big)+\ms\big((F\setminus E_1)\setminus E_2\big)$$Substitute the second line into the first. $F$ is now split into three pieces: in $E_1$; in $E_2$ but not $E_1$; in neither. $$\underset{\text{(Subadditivity)}}{\ge}\ms\big((F\cap E_1)\cup((F\setminus E_1)\cap E_2)\big)+\ms\big((F\setminus E_1)\setminus E_2\big)$$Merge the first two pieces: the outer measure of their union is at most the sum of their outer measures. $$= \ms\big(F\cap\underbrace{(E_1\cup E_2)}\big)+\ms\big(F\setminus\underbrace{(E_1\cup E_2)}\big).$$The first two pieces together are exactly the points of $F$ in $E_1$ or in $E_2$; the last piece is the points of $F$ in neither. This gives (3.2) for $E_1\cup E_2$, and Rmk 3.2 says that suffices.

Step 2 $\ms|_{\M^*}$ is finite additive

$E_1,E_2\in\M^*$ disjoint sets, let $F\subseteq X$.

$$\ms\big(F\cap(E_1\cup E_2)\big) = \ms\big(F\cap(E_1\cup E_2)\cap E_1\big)+\ms\big((F\cap(E_1\cup E_2))\setminus E_1\big)\underset{(\text{used } E_1\cap E_2 = \emptyset)}{=}\ms(F\cap E_1)+\ms(F\cap E_2),$$Measurability of $E_1$ with test set $F\cap(E_1\cup E_2)$. Then: $(F\cap(E_1\cup E_2))\cap E_1 = F\cap E_1$, and removing $E_1$ from $F\cap(E_1\cup E_2)$ leaves $F\cap E_2$ because $E_2$ doesn't meet $E_1$.

with $F = X\Rightarrow\ms(E_1\cup E_2) = \ms(E_1)+\ms(E_2)$$X\cap(E_1\cup E_2) = E_1\cup E_2$, $X\cap E_i = E_i$.

By induction, if $E_1,\dots,E_n\in\M^*$ pairwise disjoint $$\ms\Big(F\cap\bigcup_{k=1}^n E_k\Big) = \sum_{k=1}^n\ms(F\cap E_k)\quad\forall F\subseteq X\tag{4.1}$$Inductive step: $\bigcup_{k\lt n}E_k\in\M^*$ by Step 1 (iii)′ (repeated), and it's disjoint from $E_n$. Apply the two-set identity to these two sets, then the inductive hypothesis to the first term.

Step 3 $\ms|_{\M^*}$ is countably additive.

$E_n\in\M^*$, $n\in\N$, pairwise disjoint

claim $\displaystyle\bigcup_{n=1}^\infty E_n\in\M^*$ and $\displaystyle\ms\Big(\bigcup_{n=1}^\infty E_n\Big) = \sum_{n=1}^\infty\ms(E_n)$ (4.2)

let $F\subseteq X$. know $\forall m\in\N$ $\bigcup_{n=1}^m E_n\in\M^*$ ((iii)′ step 1)

$$\text{So}\quad\ms(F) = \ms\Big(F\cap\Big(\bigcup_{n=1}^m E_n\Big)\Big)+\ms\Big(F\setminus\Big(\bigcup_{n=1}^m E_n\Big)\Big)$$

The finite union is measurable; test it on $F$.

$$\underset{(\text{by }(4.1))}{=}\sum_{n=1}^m\ms(F\cap E_n)+\ms\Big(F\setminus\Big(\bigcup_{n=1}^m E_n\Big)\Big)$$

Formula (4.1) splits the first term along the disjoint measurable $E_1,\dots,E_m$.

$$\underset{\text{(monotonicity)}}{\ge}\sum_{n=1}^m\ms(F\cap E_n)+\ms\Big(F\setminus\Big(\bigcup_{n=1}^\infty E_n\Big)\Big)$$

Removing more sets leaves a smaller set: $F\setminus\bigcup_{n=1}^\infty E_n\subseteq F\setminus\bigcup_{n=1}^m E_n$. The point of this step: the right side's last term no longer depends on $m$.

let $m\to+\infty$; get

$$\ms(F)\ge\sum_{n=1}^\infty\ms(F\cap E_n)+\ms\Big(F\setminus\Big(\bigcup_{n=1}^\infty E_n\Big)\Big)\tag{4.3}$$

The inequality holds for every $m$, and the partial sums increase to the full series.

$$\underset{\text{(subadditivity)}}{\ge}\ms\Big(\bigcup_{n=1}^\infty(F\cap E_n)\Big)+\ms\Big(F\setminus\Big(\bigcup_{n=1}^\infty E_n\Big)\Big)$$

Countable subadditivity of $\ms$ applied to the sets $F\cap E_n$.

$$= \ms\Big(F\cap\Big(\bigcup_{n=1}^\infty E_n\Big)\Big)+\ms\Big(F\setminus\Big(\bigcup_{n=1}^\infty E_n\Big)\Big).$$

Distributivity: $\bigcup_n(F\cap E_n) = F\cap\bigcup_n E_n$. This is (3.2) for the union, so the union is measurable (and in fact, with subadditivity, equality holds throughout: "(=)" in the notes).

Thus $\bigcup_{n=1}^\infty E_n\in\M^*$, and with $F := \bigcup_{n=1}^\infty E_n$ $$(4.3)\Rightarrow\ms\Big(\bigcup_{n=1}^\infty E_n\Big)\ge\sum_{n=1}^\infty\ms(E_n)\quad(\le\text{ always!})$$With this $F$: $F\cap E_n = E_n$ and $F\setminus\bigcup E_n = \emptyset$, so (4.3) reads $\ms(\bigcup E_n)\ge\sum\ms(E_n)+0$. The reverse is countable subadditivity, valid for any outer measure.

step 5 [Completeness]

claim $\ms|_{\M^*}:\M^*\to[0,+\infty]$ is complete.

let $E\in\M^*$, $\ms(E) = 0$ let $F\subseteq E$ ? $F\in\M^*$?

let $A\subseteq X$. Then $$\ms(A) = \underbrace{\ms(A\cap E)}_{\subseteq E\ +\ \text{monotonicity}\ =0}+\ms(A\setminus E) = \ms(A\setminus E).\tag{4.3*}$$$E$ is measurable, tested on $A$. The first term is the outer measure of a subset of the null set $E$, hence $0$.

$$\ms(A\setminus F) = \underbrace{\ms((A\setminus F)\cap E)}_{\subseteq E\ +\ \text{monotonicity}\ =0}+\ms((A\setminus F)\setminus E)\underset{F\subseteq E}{=}\ms(A\setminus E)\tag{4.3**}$$Again $E$ measurable, now tested on $A\setminus F$. Since $F\subseteq E$, removing $F$ and then $E$ is the same as removing $E$: $(A\setminus F)\setminus E = A\setminus E$.

(4.3*) + (4.3**) $\ms(A) = \ms(A\setminus F) = \underbrace{\ms(A\cap F)}_{\subseteq F,\ \text{monotonicity},\ \ms(F) = 0}+\ms(A\setminus F)$.Both equal $\ms(A\setminus E)$. And $\ms(A\cap F)\le\ms(F)\le\ms(E) = 0$, so adding it changes nothing. The result is exactly the measurability identity for $F$ with test set $A$. (Alternatively: Rmk 3.2 (ii), sets of outer measure zero are always measurable.)

Hence $F\in\M^*$. ■

(i) Def 3.14 … the class of all $(\mathcal L^N)^*$-measurable sets is the σ-algebra of Lebesgue measurable sets, $\mathcal L(\R^N)$.

Carathéodory Thm $\Rightarrow(\mathcal L^N)^*|_{\mathcal L(\R^N)}$ is a complete measure, called the $N$-dimensional Lebesgue measure, denoted by $\mathcal L^N$.

Prop 3.13 all Borel sets of $\R^N$ are Lebesgue measurable. In particular, balls are Lebesgue measurable.

Scaling + translation invariance $\forall x\in\R^N$, $r\gt0$ $$\mathcal L^N(B(x,r)) = \mathcal L^N(B(0,r)) = r^N\underbrace{\mathcal L^N(B(0,1))}_{\alpha_N}$$Translation: Rmk 2.12. Scaling: if $\{R_n\}$ covers $E$ then $\{rR_n\}$ covers $rE$, and $\ell(rR) = r^N\ell(R)$ since each of the $N$ side lengths is multiplied by $r$. So $(\mathcal L^N)^*(rE) = r^N(\mathcal L^N)^*(E)$ (apply with $r$ and $1/r$). Finally $B(0,r) = rB(0,1)$.
