(3) $\mathcal H^s_0\equiv0$ if $s\gt N$ in $\R^N$

Subdivide the unit cube $Q := [-\frac12,\frac12]^N$ into $m^N$ subcubes of side length $\frac1m$ and diameter $\frac{\sqrt N}{m}$.

Let $\delta = \frac{\sqrt N}{m}$. Then $$\mathcal H^s_{\sqrt N/m}(Q)\le\sum_{n=1}^{m^N}\alpha_s\Big(\frac{\sqrt N}{2m}\Big)^s = \alpha_s\Big(\frac{\sqrt N}{2}\Big)^s\frac1{m^{s-N}}\underset{m\to+\infty}{\longrightarrow}0$$The $m^N$ subcubes form an admissible cover at scale $\delta$ (diameter $\le\delta$; use a tiny bit larger $\delta$ for strict inequality). All terms are equal, so the sum is $m^N\cdot\alpha_s(\sqrt N/2)^s m^{-s} = \alpha_s(\sqrt N/2)^s m^{N-s}$, and $N - s\lt0$.

$\Rightarrow\mathcal H^s_0(Q) = \lim_{\delta\to0}\mathcal H^s_\delta(Q) = 0.$The limit along $\delta = \sqrt N/m$ is $0$; since $\delta\mapsto\mathcal H^s_\delta(Q)$ is monotone, the full limit as $\delta\to0$ equals the limit along this sequence.

$\R^N$ can be written as a countable union of translations of the unit cube $\Rightarrow\mathcal H^s_0(\R^N) = 0$.$\R^N = \bigcup_{k\in\Z^N}(k+Q)$, countably many; each has $\mathcal H^s_0 = 0$ by translation invariance (4); countable subadditivity.

Fact #1 If $A\subseteq\R$ is Lebesgue measurable and $\mathcal L^1(A)\gt0$ then $\exists E\subset A$ that is not measurable. (Proof: uses inner and outer regularity of $\mathcal L^1$)

Fact #1 $\Rightarrow\exists E\subseteq g(\mathfrak C)$ non measurable.This finishes the claim: let $F := g^{-1}(E)\subseteq\mathfrak C$. $F$ is Lebesgue measurable (subset of a null set, completeness). If $F$ were Borel, then $g(F) = (g^{-1})^{-1}(F)$ would be Borel, since preimages of Borel sets under the continuous map $g^{-1}$ are Borel (the sets $B$ with $(g^{-1})^{-1}(B)$ Borel form a σ-algebra containing the open sets). Borel sets are measurable, but $g(F) = E$ is not. So $F$ is Lebesgue measurable and not Borel.
