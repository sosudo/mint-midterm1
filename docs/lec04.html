$\nexists\ \mu:\mathcal P(\R)\to[0,+\infty]$ s.t.

  1. $\mu(I) = \ell(I)$ $\forall I$ interval of $\R$
  2. $\displaystyle\mu\Big(\bigcup_{n=1}^\infty A_n\Big) = \sum_{n=1}^\infty\mu(A_n)$ for every disjoint family $\{A_n\}\subset\mathcal P(\R)$
  3. $\mu(t+A) = \mu(A)$ $\forall A\subseteq\R$, $t\in\R$.

(i)–(iii) are all the properties that we used for $(\mathcal L^1)^*$ in Rmk 2.13, contradicting (ii) (additivity).

  • monotonicity
    (i) $\Rightarrow\mu(\emptyset) = \ell(\emptyset) = 0$$\emptyset = (a,a)$ is an (empty) interval, whose length is $a - a = 0$.
    $A\subseteq B\subseteq\R$, $B = A\,\dot\cup\,(B\setminus A)\,\dot\cup\,\emptyset\,\dot\cup\,\emptyset\dots$
    $$\text{(ii)}\quad \mu(B) = \mu(A) + \underbrace{\mu(B\setminus A)}_{\ge0} + \underbrace{\mu(\emptyset)+\dots}_{=0}\ \ge\mu(A)$$

    The sequence $A, B\setminus A, \emptyset,\emptyset,\dots$ is pairwise disjoint with union $B$, so (ii) applies. All values of $\mu$ are in $[0,+\infty]$, so dropping the non-negative term $\mu(B\setminus A)$ can only decrease the right side.

  • Subadditivity $A_n\subseteq\R$ $$\bigcup_{n=1}^\infty A_n = \bigcup_{n=1}^\infty A'_n,\qquad A'_n := A_n\setminus\Big(\bigcup_{j\lt n}A_j\Big)\ \text{pairwise disjoint}$$
    $$\text{(ii)}\Rightarrow\mu\Big(\bigcup_{n=1}^\infty A_n\Big) = \mu\Big(\bigcup_{n=1}^\infty A'_n\Big)\underset{\text{(ii)}}{=}\sum_{n=1}^\infty\mu(A'_n)\le\sum_{n=1}^\infty\mu(A_n)$$

    Same union: $A'_n\subseteq A_n$ gives $\subseteq$; conversely, a point $x$ of $\bigcup A_n$ lies in some first $A_n$ (smallest $n$), and then $x\in A'_n$.

    Disjoint: if $m\lt n$, $A'_n$ has removed $A_m\supseteq A'_m$.

    Last $\le$: $A'_n\subseteq A_n$ and monotonicity, just proved.

    This "disjointification" trick will be used constantly.

    (monotonicity, just proved) ■

3. σ-Algebras / Measurable Sets

Just saw that for $\ms$ outer measure (e.g., $(\mathcal L^1)^*$) it may happen $$A\cap B = \emptyset\Rightarrow\mu(A\cup B)\lt\mu(A)+\mu(B).$$

Carathéodory: restrict $\ms:\mathcal P(X)\to[0,+\infty]$ to a smaller class, which are the sets $B\subset\mathcal P(X)$ s.t. $\forall A$ s.t. $A\cap B = \emptyset$ $$\ms(A\cup B) = \ms(A)+\ms(B).\tag{3.1}$$

Let $X\ne\emptyset$, $\ms:\mathcal P(X)\to[0,+\infty]$ outer measure. A set $A\subseteq X$ is said to be $\ms$-measurable if $$\forall F\subseteq X\qquad \ms(F) = \ms(F\cap A)+\ms(F\setminus A).\tag{$*$}$$

(i) Subadditivity of $\ms$: $\ms(F)\le\ms(F\cap A)+\ms(F\setminus A)$ Always!$F = (F\cap A)\cup(F\setminus A)$; apply countable subadditivity (Def 2.6 (iii)) to the sequence $F\cap A, F\setminus A,\emptyset,\emptyset,\dots$, using $\ms(\emptyset) = 0$.

If want to show $(*)$, need to prove $\boxed{\ge}$ i.e., $\forall F\subseteq X$ $$\boxed{\ms(F)\ge\ms(F\cap A)+\ms(F\setminus A)\quad\text{if }\ms(F)\lt+\infty.}\tag{3.2}$$ (if $\ms(F) = +\infty$, $\ge$ is automatic)

(ii) if $\ms(E) = 0\Rightarrow E$ is $\ms$-measurableWe verify (3.2) for every $F$, as written out next: the piece inside $E$ is controlled by $E$ (which is null), the piece outside by $F$.

Let $F\subseteq X$

$$\underbrace{\ms(F\cap E)}_{\le\ms(E)}+\underbrace{\ms(F\setminus E)}_{\le\ms(F)}\le\underbrace{\ms(E)}_{=0}+\ms(F) = \ms(F).$$

Monotonicity twice: $F\cap E\subseteq E$ and $F\setminus E\subseteq F$. Then $\ms(E) = 0$. This is exactly (3.2).

monotonicity

$\ms:\mathcal P(X)\to[0,+\infty]$ outer measure. If $B\subseteq X$ is $\ms$-measurable. Then $\forall A\subseteq X$, $A\cap B = \emptyset$ $$\ms(A\cup B) = \ms(A)+\ms(B).$$

$B$ $\ms$ meas. $$\ms(A\cup B) = \ms\big((A\cup B)\cap B\big)+\ms\big((A\cup B)\setminus B\big)$$Definition 3.1 of measurability of $B$, applied with the test set $F = A\cup B$. $$= \ms(B)+\ms(A)\ \text{because } A\cap B = \emptyset.$$$(A\cup B)\cap B = B$ always; $(A\cup B)\setminus B = A\setminus B = A$ since $A$ and $B$ are disjoint. ■

Carathéodory Thm (Thm 4.9): the restriction of $$\ms:\M^*\to[0,+\infty]$$ $$\M^* := \{E\subseteq X,\ E\ \ms\text{-measurable}\}\tag{3.3}$$ then $\ms$ is countably additive (hence (3.1) holds).

Also, $\M^*$ has important properties, and is what we call a σ-algebra (sigma algebra).

Let $X\ne\emptyset$, $\M\subseteq\mathcal P(X)$ is a σ-algebra if:

  1. $\emptyset\in\M$
  2. $E\in\M\Rightarrow X\setminus E\in\M$
  3. $E_n\in\M$, $n\in\N$, then $\bigcup_{n=1}^\infty E_n\in\M$

$(X,\M)$ is called a measurable space.

Let $X\ne\emptyset$, $\ms:\mathcal P(X)\to[0,+\infty]$ outer measure. $\ms$ is said to be regular if: $$\forall E\subseteq X\ \exists F\in\M^*\ \text{s.t.}\ E\subseteq F\ \text{and}\ \ms(E) = \ms(F).$$

$(X,\M)$ measurable space. Then

  1. $X\in\M$
  2. $E,F\in\M\Rightarrow E\cup F,\ E\cap F,\ E\setminus F\in\M$
  3. $E_n\in\M$, $n\in\N\Rightarrow\bigcap_{n=1}^\infty E_n\in\M$.

$E_n$ are disjoint, $\displaystyle F\setminus C = \bigcup_{n=0}^\infty E_n$ ($C$ is closed) (3.4)The distance bands $[1,\infty)$, $[\frac12,1)$, $[\frac13,\frac12)$, … are disjoint and cover $(0,\infty)$. The point is that every $x\in F\setminus C$ has $\operatorname{dist}(x,C)\gt0$: since $C$ is closed, $X\setminus C$ is open, so some ball $B(x,r)$ misses $C$, giving $\operatorname{dist}(x,C)\ge r\gt0$. claim 2 $n\ge0$ $\operatorname{dist}(E_{2n},E_{2n+2})\gt0$

$x\in E_{2n}$, $y\in E_{2n+2}$

$$\underset{x\in E_{2n}}{\frac1{2n+1}\le\operatorname{dist}(x,C)}\le d(x,y)+\operatorname{dist}(y,C)\le d(x,y)+\underset{y\in E_{2n+2}}{\frac1{2n+2}}$$

First: definition of $E_{2n}$. Middle: the function $\operatorname{dist}(\cdot,C)$ is 1-Lipschitz — for any $c\in C$, $d(x,c)\le d(x,y)+d(y,c)$; take inf over $c$. Last: $y\in E_{2n+2}$ means $\operatorname{dist}(y,C)\lt\frac1{2n+2}$.

$\Rightarrow d(x,y)\ge\frac1{2n+1}-\frac1{2n+2}\gt0$

$\ms$ is a metric outer meas.

$$+\infty\gt\ms(F)\ge\ms\Big(\bigcup_{n=0}^k E_{2n}\Big) = \sum_{n=0}^k\ms(E_{2n})\quad\forall k$$

$\ge$: monotonicity, since all $E_{2n}\subseteq F$.

$=$: induction on $k$ using the metric property: $\bigcup_{n\lt k}E_{2n}$ and $E_{2k}$ are a positive distance apart. Indeed, the same estimate as claim 2 shows $\operatorname{dist}(E_{2n},E_{2k})\ge\frac{1}{2n+1}-\frac1{2k}\gt0$ for all $n\lt k$, and there are finitely many $n$, so the minimum is positive.

⇓ $\displaystyle\sum_{n=0}^k\ms(E_{2n})\le\ms(F)$

$\displaystyle\Rightarrow\sum_{n=0}^\infty\ms(E_{2n})\le\ms(F)$The partial sums of a series of non-negative terms are increasing and bounded by $\ms(F)\lt\infty$, so the series converges and its sum (the sup of the partial sums) is $\le\ms(F)$.

Similarly, $\displaystyle\sum_{n=1}^\infty\ms(E_{2n-1})$ conv. $$\Rightarrow\boxed{\sum_{n=0}^\infty\ms(E_n)}\ \text{converges.}\tag{3.5}$$

claim 3 $\forall k\in\N$, $\operatorname{dist}\Big(F\cap C,\ \bigcup_{n=0}^k E_n\Big)\gt0$

$x\in F\cap C$, $y\in\bigcup_{n=0}^k E_n$ $$\frac1{k+1}\le\operatorname{dist}(y,C)\le d(x,y)$$$y\in E_n$ with $n\le k$, so $\operatorname{dist}(y,C)\ge\frac1{n+1}\ge\frac1{k+1}$. And $x\in C$, so the distance from $y$ to $C$ is at most $d(y,x)$. So every such pair is at least $\frac1{k+1}$ apart.

$\ms$ metric outer measure:

$$\ms(F\cap C)+\ms(F\setminus C) = \ms(F\cap C)+\ms\Big(\bigcup_{n=0}^\infty E_n\Big) \underset{(3.4)}{=} \ms(F\cap C)+\ms\Big(\bigcup_{n=0}^k E_n\cup\bigcup_{n=k+1}^\infty E_n\Big)$$

(3.4) says $F\setminus C$ is the union of all layers; we just split the union at index $k$.

$$\underset{\text{subad.}}{\le}\ms(F\cap C)+\ms\Big(\bigcup_{n=0}^k E_n\Big)+\underbrace{\ms\Big(\bigcup_{n=k+1}^\infty E_n\Big)}_{\le\sum_{n=k+1}^\infty\ms(E_n)}$$

Subadditivity of $\ms$, used twice: once to split the union in two, and once (countably) on the tail.

$$\underset{\text{(claim 3)}}{=}\ms\Big(\underbrace{(F\cap C)\cup\bigcup_{n=0}^k E_n}_{\subseteq F}\Big)+\sum_{n\ge k+1}\ms(E_n)$$

By claim 3 the two sets $F\cap C$ and $\bigcup_{n\le k}E_n$ are a positive distance apart, so the metric property merges their outer measures into the outer measure of the union. This is the heart of the proof: near $C$ we can't separate, but we've pushed everything near $C$ into the tail.

$$\underset{\text{mon.}}{\le}\ms(F)+\underbrace{\sum_{n=k+1}^\infty\ms(E_n)}_{\to0\text{ as }k\to+\infty}\qquad\forall k$$

Monotonicity: the union is a subset of $F$. The tail of a convergent series (3.5) tends to $0$.

let $k\to+\infty$ and get $$\ms(F\cap C)+\ms(F\setminus C)\le\ms(F).\ \blacksquare$$
