6. Regularity

Regularity properties of measures concern the possibility of approximating in measure one class of sets, e.g., nonmeasurable sets, by another class of sets, e.g., measurable sets.

As we'll see, Lebesgue measure is Borel regular in the sense that Lebesgue measurable sets can be approximated in measure from outside by open sets and from the inside by closed sets. Further, they can be approximated by Borel sets up to sets of measure zero.

An outer measure $\ms:\mathcal P(X)\to[0,+\infty]$ is said to be regular if for all $E\subseteq X$ there exists a $\ms$-measurable set $F\subset X$ such that $E\subset F$ and $\ms(E) = \ms(F)$.

N.B. In Prop 4.6 we proved this result for measures.

Since $\ms$ is regular, for all $n\in\N$ let $F_n$ be $\ms$-measurable with $E_n\subseteq F_n$, $\ms(E_n) = \ms(F_n)$. and the result follows. ■

This proposition may fail if $\ms$ is not regular. Let $X := \N$, and define $$\ms(E) := \begin{cases}0 & \text{if } E = \emptyset,\\ 1 & \text{if } E \text{ is finite},\\ 2 & \text{if } E \text{ is infinite},\end{cases}\quad E\subseteq\N.$$

Then $\ms$ is an outer measure$\ms(\emptyset) = 0$. Monotone: a subset of a finite set is finite (or empty), so values can only go up with inclusion. Countably subadditive: if $\bigcup E_n$ is non-empty, some $E_n$ is non-empty (sum $\ge1$); if the union is infinite then either some $E_n$ is infinite (sum $\ge2$) or infinitely many $E_n$ are non-empty (sum $=\infty$)., and if $E_n := \{1,\dots,n\}$ then $$2 = \ms\Big(\bigcup_{n=1}^\infty E_n\Big)\ne\lim_{n\to+\infty}\ms(E_n) = 1.$$

Given an outer measure $\ms:\mathcal P(X)\to[0,+\infty]$, we can construct a regular outer measure by defining $$\nu^*(E) := \inf\{\ms(F) : E\subset F,\ F\text{ is }\ms\text{-measurable}\}$$ It can be shown that

  1. $E$ is $\ms$-measurable $\Rightarrow E$ is $\nu^*$-measurable and $\ms(E) = \nu^*(E)$.
  2. $E$ is $\nu^*$-measurable and $\nu^*(E)\lt+\infty\Rightarrow E$ is $\ms$-measurable.

Let $X$ be a topological space, and let $\ms:\mathcal P(X)\to[0,+\infty]$ be an outer measure.

  1. A set $E\subset X$ is said to be inner regular if $$\ms(E) = \sup\{\ms(K) : K\subset E,\ K\text{ compact}\},$$ and is outer regular if $$\ms(E) = \inf\{\ms(U) : E\subset U,\ U\text{ open}\}.$$
  2. a set $E\subset X$ is said to be regular if it is both inner and outer regular.

Let $X$ be a topological space, and let $\ms:\mathcal P(X)\to[0,+\infty]$ be an outer measure.

Still, a partial result toward Borel regular $\Rightarrow$ Radon is:

Let $X$ be a locally compact Hausdorff space such that every open set $A\subseteq X$ is σ-compact (i.e., $A = \bigcup_{n=1}^\infty K_n$, $K_n$ compact). Let $\ms:\mathcal P(X)\to[0,+\infty]$ be a Borel outer measure such that $\ms(K)\lt+\infty$ for every compact set $K\subseteq X$.

Then every Borel set is inner regular and outer regular.

If, in addition, $\ms$ is a Borel regular outer measure, then it is a Radon outer measure. [see also Thm 6.21]
